Personal backup utility

Secure backups for the Zen Mindfulness project

Zen Mindfulness Backup is a privately operated tool used by the project owner to preserve recoverable copies of the Zen Mindfulness software project's Git history in Google Drive.

What the backup tool does

When configured and authorized, the tool creates a Git-history recovery archive, stores a copy in each of two owner-authorized Google Drive accounts, and checks the downloaded archives against their original SHA-256 checksums.

This site provides information about the backup application's requested Google permissions. It does not provide a public account-registration or sign-in service.

Google Drive access

The application requests the limited drive.file permission to create and access files used with the application. The owner grants access separately for each Google account. It is not intended to browse unrelated personal Drive files.
