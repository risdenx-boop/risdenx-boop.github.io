Terms of use

Zen Mindfulness Backup is a personal, owner-operated backup utility, not a commercial product or public hosting service. The application is intended solely to preserve and verify owner-authorized copies of Zen Mindfulness project Git history.

Authorization

Only the account owner or an authorized operator may connect Google Drive accounts or operate backups. Use of the tool requires permission to access the selected repository and Google Drive destination accounts.

Backup limitations

The tool is intended to preserve committed, pushed Git branch and tag history. It does not automatically protect every local uncommitted file, external database, device, credential, or third-party service. Backups should be independently verified and occasionally restored to test recoverability.

Availability and changes

Backups depend on Google, GitHub, valid authorization, available storage, and successful scheduled runs. The operator may revise this documentation or discontinue the private utility.

Privacy and support

See the privacy policy. Contact zenmindfulnessbackup@gmail.com with questions.
