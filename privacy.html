Privacy policy

Zen Mindfulness Backup is a privately operated backup tool for the Zen Mindfulness software project. It is intended for use only by its owner and accounts the owner authorizes. This policy describes the application's intended Google API data handling. No public signup or commercial service is offered.

Information accessed

With authorization, the backup utility may read the Google account email address to verify that it is connected to the correct account. It uses Google's drive.file permission to create and access backup archives and related metadata in owner-approved Google Drive locations. It may read the files it creates or that the owner uses with the application, including downloading copies to verify their integrity.

How the information is used

Google data is used only for the backup workflow: identifying the authorized destination account, creating Git-history backup archives and associated records, checking their location and size, and verifying downloaded file bytes using SHA-256 checksums. It is not used for targeted advertising, profiling, or sale of personal information.

Where data is processed and stored

Backups are stored in the owner's selected Google Drive accounts. When the automated workflow is enabled, GitHub Actions processes backup data temporarily to create and verify archives. The workflow is designed to keep OAuth credentials in GitHub Actions encrypted secrets rather than publishing them in source code, public web pages, or backup reports. GitHub and Google separately operate their services under their own applicable terms and privacy policies.

Sharing and disclosure

The operator does not sell Google user data or share it with advertisers. Backup data is processed by Google Drive and GitHub Actions as needed to provide the owner's requested backup workflow; information may also be disclosed if required by applicable law.

Retention and deletion

Backup archives remain in the selected Google Drive accounts until the account owner removes them or changes the backup arrangement. Temporary workflow files may be removed when a run finishes; GitHub may retain Actions logs and artifacts under its configured retention settings. The owner may remove stored backup files directly in Google Drive and may revoke this application's authorization through Google Account security settings. Revoking access stops future authorized API access but does not itself delete copies already stored in Drive.

Security

The proposed workflow uses HTTPS to communicate with Google APIs, limits access using the Google drive.file scope, checks the destination account, and verifies downloaded archive hashes. No technical control is an absolute security guarantee. Backup archives may contain private project history and must not be made publicly accessible.

Your choices and contact

Granting Google Drive access is voluntary. The owner can revoke it in their Google Account and can delete backup files in Google Drive. For questions or requests about this application, email zenmindfulnessbackup@gmail.com.
